# Tremor
AdaHack 2026, CompSoc Challenge 7.

Public BGS seismic data, classic STA/LTA and travel-time-constrained multi-station association. This repository contains the static demonstration build. It includes historical cases, replay, waveform evidence and the illustrated notebook. Live acquisition and fresh detector runs require the local Python project.

The three methods are Single-station STA/LTA, Standard multi-station trigger, and Travel-time-constrained association.

The retrospective audit finds 17/26, 21/26 and 21/26 catalogue events respectively. Continuous candidate workload is 28.9, 32.9 and 22.4 per day. Unmatched candidates require review.

`index.html` embeds compressed recorded data and display assets. Use a current browser supporting DecompressionStream. No data is sent to a detector backend. Public map tiles require a network connection.
